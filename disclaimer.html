Accuracy of results

WhichPhone detects your device by reading signals your browser shares, such as the user agent, client hints, screen size, and hardware values. These signals are not always exact. Results are approximate and should be treated as informational only.

?

Model groups

Some devices — particularly iPhones and certain Android models — cannot be uniquely identified because multiple models share identical browser fingerprints. In these cases, WhichPhone shows the closest matching group rather than a single exact model.

No professional advice

The information shown is not professional, legal, or technical advice. Do not rely on it for purchasing decisions, warranty claims, or any situation where exact hardware identification is critical.

H

Hardware values

Reported values such as RAM and CPU core count come from browser APIs that may be limited, rounded, or unavailable. For example, the Device Memory API reports approximate values and is only available in some browsers.

G

GPU information

GPU names are read from the WebGL renderer string. Browsers may mask or generalize this string for privacy, so the reported GPU may differ from the physical chip.
